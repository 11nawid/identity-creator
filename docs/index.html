Identity Creator

Free, open-source synthetic identity generator for testing, prototyping, and development.

Launch App → View on GitHub

Features

Offline-First

Works without any API key. Uses bundled data banks for names, professions, and locations.

AI-Enhanced

Optional Gemini integration for richer biographies and profile details.

Batch Generation

Create 5, 10, 25, or 50 identities at once with quick presets.

Complete Profiles

Personal, location, career, finance, physical, digital, lifestyle, and IDs.

Temporary Email

Disposable inbox via Mail.tm for each generated identity.

Export Anywhere

JSON, CSV, TXT, or PDF. Copy any section to clipboard.
